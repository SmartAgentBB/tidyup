# 🧹 비움 챌린지 (Tidyup Challenge)

연말을 맞아 불필요한 물건들을 비워내고 새로운 시작을 준비하는 웹 애플리케이션입니다.

## ✨ 주요 기능

- 📸 **사진 업로드**: 비운 물건의 사진을 간편하게 업로드
- ✍️ **간단한 기록**: 140자 이내의 짧은 메모로 비움의 순간 기록
- 📅 **타임라인**: 최신 기록이 상단에 표시되는 타임라인 뷰
- 💾 **로컬 저장**: 브라우저 로컬 스토리지에 안전하게 저장
- 🗑️ **삭제 기능**: 원하지 않는 기록은 언제든 삭제 가능

## 🚀 시작하기

### 필수 요구사항

- Node.js 18.0 이상
- npm 또는 yarn

### 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어 확인하세요.

## 🛠️ 기술 스택

- **Next.js 15** - React 프레임워크
- **TypeScript** - 타입 안정성
- **Tailwind CSS** - 스타일링
- **로컬 스토리지** - 데이터 저장 (Base64 이미지)

## 📁 프로젝트 구조

```
tidyup/
├── app/
│   ├── page.tsx          # 메인 페이지
│   ├── layout.tsx        # 루트 레이아웃
│   └── globals.css       # 글로벌 스타일
├── components/
│   ├── PostForm.tsx      # 게시물 작성 폼
│   └── PostList.tsx      # 게시물 목록
├── lib/
│   └── storage.ts        # 로컬 스토리지 유틸리티
└── public/               # 정적 파일
```

## 💡 사용 방법

1. **사진 선택**: 비운 물건의 사진을 선택합니다 (최대 5MB)
2. **내용 입력**: 무엇을 비웠는지 140자 이내로 작성합니다
3. **기록하기**: 버튼을 클릭하여 저장합니다
4. **확인하기**: 타임라인에서 나의 비움 여정을 확인합니다

## ⚠️ 주의사항

- **로컬 저장**: 데이터는 브라우저에만 저장되므로 다른 기기에서는 접근할 수 없습니다
- **저장 용량**: 브라우저 로컬 스토리지는 약 5-10MB 제한이 있습니다
- **데이터 백업**: 브라우저 캐시를 삭제하면 데이터가 사라질 수 있습니다
